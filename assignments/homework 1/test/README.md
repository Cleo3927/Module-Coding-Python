# Homework 1 Test Submission

This directory contains a test/example submission for Homework 1 (Regex + NLP Preprocessing).

## Contents

- `test.ipynb` - Main Jupyter notebook demonstrating all homework requirements
- `test_homework.py` - Python test script to verify regex patterns work correctly

## What's Included

The test submission demonstrates:

1. ✅ **Data & Context** - Sample text about AI (400+ words)
2. ✅ **Regex Extraction** - 4 patterns (emails, dates, phone numbers, dollar amounts)
3. ✅ **NLP Preprocessing** - Complete pipeline with lemmatization
4. ✅ **Regex + NLP Combo** - Number-noun pair extraction
5. ✅ **Visualization** - Bar chart of top 15 tokens
6. ✅ **Reproducibility** - All text embedded, runs top-to-bottom
7. ✅ **Comments** - Clear explanations throughout
8. ✅ **Report** - Summary of approach, challenges, and findings

## How to Use

### Run the Notebook
```bash
jupyter notebook test.ipynb
```

### Run the Test Script
```bash
python3 test_homework.py
```

## Requirements

The notebook requires:
- Python 3.7+
- nltk
- matplotlib

Install with:
```bash
pip install nltk matplotlib jupyter
```

This test submission serves as:
